存档工具箱 —— 查存档、上传、下载、还原，全在一个窗口里

==================================================
一、这是什么
==================================================
一个用来管理"游戏本地存档"的小工具。它把你自己电脑上的存档，传到你自己
的 GitHub 仓库里，换电脑、重装系统、存档被覆盖了，再一键还原回来。

它不是云存档平台，也不需要注册任何账号，唯一依赖就是你的 GitHub 仓库。
程序零依赖：不用装 Python、不用装 .NET、不用装任何运行库。

系统要求：Windows 10 / 11（64 位或 32 位都行），系统自带的 PowerShell 5.1 就够。

==================================================
二、文件清单
==================================================
存档工具箱.exe      启动器，双击它（88 KB，带图标）
存档工具箱.ps1      程序主体，必须和 exe 放在同一个文件夹
启动.vbs            备用启动方式（exe 被拦截时用这个）
说明.txt            本说明
config.txt          不用管，第一次运行会自动生成在 exe 旁边
令牌申请步骤图      在 素材\令牌申请步骤.png
素材\宣传片.mp4      宣传片（1080×1920），不看也不影响用
素材\赞助-微信.png   微信收款码（想请作者喝口水的话）
素材\赞助-支付宝.png 支付宝收款码

解压到一个固定位置（例如 D:\工具\存档工具箱），不要放在桌面随手丢，
也不要放在 Temp 里——备份文件夹是跟着程序目录走的。

==================================================
三、怎么启动
==================================================
双击 存档工具箱.exe，会直接出现窗口，没有黑色命令行窗口。

第一次运行时 Windows 可能弹"Windows 已保护你的电脑 / 未知发布者"，这是
因为程序没有购买代码签名证书（个人工具，一年几千块，没必要）。处理办法：
  · 弹窗里点"更多信息"，再点"仍要运行"；
  · 或者右键 exe → 属性 → 勾选"解除锁定" → 确定，之后就不会再提示。

如果 exe 怎么都打不开（被杀软拦截），双击 启动.vbs，效果完全一样。

==================================================
四、第一次配置（只做一次）
==================================================
打开左侧"仓库连接"，填三个空，点"保存"：

  用户名 / 仓库   例：你的GitHub用户名/仓库名，比如 XQ-China/saves
                  （就是浏览器地址栏 github.com/ 后面那两段，斜杠别丢）
  分支            填 main（主分支）。这里是分支名，不是仓库名，一般就是 main
  Token           见下面第五节。只下载别人的公开仓库可以不填

填完点"测试连接"，日志区出现"连接成功"就说明配置对了。

情况 A：你只是下载别人分享的存档（公开仓库）
  · 用户名/仓库 填分享者给你的那个仓库
  · 分支填 main
  · Token 留空也能下载，但 GitHub 对未登录的请求限制为每小时 60 次，
    下得多了可能提示超限，等一小时或补一个 Token 就好

情况 B：你要把自己电脑的存档传上去（强烈建议用私有仓库）
  · 仓库必须是你的，并且必须有 Token，否则上传会失败
  · 仓库设成私有后，下载也必须带 Token，不带会提示 404

==================================================
五、令牌（Token）怎么申请（一次性，5 分钟）
==================================================
（照着压缩包里的 令牌申请步骤.png 一步步点，图示最直观）
1. 登录 GitHub，点右上角头像 → 设置（Settings）
2. 左侧菜单拉到最底下 → 开发者设置（Developer settings）
3. 展开 个人访问令牌（Personal access tokens）→ 选 令牌（经典）（Tokens (classic)）
   别选 细粒度（Fine-grained），那种令牌建不了仓库，还会权限不足
4. 点右上 生成新令牌（Generate new token）→ 选 生成新令牌（经典）（Generate new token (classic)）
5. 注意（Note）随便填个名字，比如 save-toolbox；
   到期（Expiration）选 不设过期（No expiration）
6. 选择范围（Select scopes）里只勾 repo（对私人仓库的完全控制），
   其余全部不勾（子项会自动带上，不用单独勾）
7. 点最底部 生成令牌（Generate token），复制 ghp_ 开头那串，
   粘到工具的 令牌（Token）框里，点保存

注意：中文译名可能会不一样，找不到就切换到英文界面。

==================================================
六、查找存档
==================================================
1. 输入游戏名（中文名、英文文件夹名都行，也可以直接粘游戏安装目录的路径）
2. 点"查找存档"，程序按这个顺序找，找到就返回：
   ① 游戏安装目录里名为 SaveGames / Saved / Save / Saves / Worlds 的文件夹
      （Saved\SaveGames\Steam\数字ID 这种多层会一路钻到最里层；泰拉瑞亚 tModLoader\Worlds、
       Minecraft 的 saves\世界名 也认）
   ② AppData\LocalLow
   ③ AppData\Roaming、文档、文档\My Games、Saved Games
   （不扫 AppData\Local，那是日志；日志/缓存/Config/Crash 等目录一律跳过）
   存档文件只认 .sav、.json 这类后缀
3. 结果表每个存档文件一行：游戏名 / 存档文件 / 大小 / 存档位置 / 状态
4. 不确定叫什么，就点"列出全部候选"，把所有带存档特征的目录列出来自己挑
5. 选中一行（或勾表头左侧那个小方框＝全选），点"填入上传区"，
   会自动跳到上传页并填好游戏名、目录和文件
6. 格子里路径太长看不全时，鼠标停在上面会弹出小框显示完整内容
7. SteamID 目录（Saved\7656xxxxx\SaveGames 里那串数字）不用手动改：
   程序会自己认出当前电脑的 ID，上传时存成 {STEAMID} 占位符，
   别人还原时自动换成他自己的 ID，只存档、不存 ID

小提示：搜不到多半是名字对不上，试试英文文件夹名（比如 Stardew Valley、
Minecraft），或者直接把游戏安装目录粘进搜索框。

==================================================
七、上传存档
==================================================
1. 确认游戏名（会成为仓库里的文件夹名，例如 存档/星露谷物语/）
2. 确认存档目录和文件列表（可多选，选目录会自动列出里面的存档文件）
3. 点"上传到仓库"，程序会逐个文件上传，同时更新该游戏的 meta.json
   和仓库首页 README 的清单表格
4. 上传时文件名不变，同名文件会被覆盖（好比你今天传的进度会盖掉昨天的）
5. 单个文件上限 100 MB（GitHub 硬限制），存档一般都远小于这个

仓库里的目录结构：
  存档/<游戏名>/<存档文件>
  存档/<游戏名>/meta.json     记录游戏名、本机路径、文件清单、更新时间
  README.md                   首页表格，自动生成

==================================================
八、下载还原
==================================================
1. 点"预览"，先看会还原到哪些路径——这一步只读，不写任何文件
2. 表格上方有搜索框，输入游戏名或文件名可以筛选查看
3. 点"开始还原"才真正覆盖：
   · 可以多选（Ctrl / Shift 选多行），只还原选中的
   · 也可以勾表格左上角的小方框＝全选
   · 一行都没选中就还原全部
4. 覆盖之前，程序会把原文件备份到 程序目录\备份\<游戏名>\<时间戳>\，
   备份里的文件名和原来一模一样，想回退直接把这个文件夹拷回原目录就行
5. 想换备份位置：在 config.txt 里写 backup_dir=D:\存档备份
6. "清除备份"会把整个备份文件夹清空（不管什么后缀），删之前会弹一次确认
7. "清除云存档"删的是仓库里的 存档\<游戏名>\ 整个目录（存档文件 + meta.json），
   一次删一条提交，只动云端、不动你电脑里的存档文件；勾选哪行就删哪行，
   一行没勾就按预览列表全删，删之前会弹一次确认

还原到哪个目录，优先用仓库里 meta.json 记的原路径；如果换了电脑、
路径不存在了，会退回 config.txt 里 dest_root 指定的目录（没填就用
程序旁边的 还原 文件夹）。

==================================================
九、常见问题
==================================================
Q：提示 404（Not Found，找不到）
   · 用户名或仓库名写错（注意是 用户名/仓库，中间是斜杠）
   · 仓库是私有但没填 Token
   · 令牌的 仓库访问（Repository access）里没勾选这个仓库

Q：提示 401（Bad credentials，凭证无效）
   令牌复制不全、过期了，或者粘贴时多了空格，重新生成一个

Q：提示 403（rate limit，请求次数超限）
   未登录请求每小时 60 次，填一个令牌就变成 5000 次

Q：提示 409（conflict，冲突）
   同一秒内连续上传同一个文件，稍等几秒重试

Q：窗口一闪就没了
   存档工具箱.ps1 不在 exe 旁边，或者被安全软件删了，重新解压

Q：杀毒软件报毒或拦截
   无签名的小工具常见误报。不放心可以把压缩包传到 VirusTotal 自查，
   或者把整个文件夹加进白名单

Q：换电脑后存档还原到别的地方了
   在 config.txt 里设置 dest_root，比如 dest_root=D:\还原存档

Q：想改备份位置
   config.txt 里 backup_dir=D:\存档备份，留空就是 程序目录\备份

Q：能不能多人共用一个仓库
   可以，但别共用同一个 Token；共用仓库时各人的 meta.json 会互相覆盖

==================================================
十、config.txt 各行的意思
==================================================
repo=            用户名/仓库，例如 XQ-China/saves
branch=          分支名，一般是 main
token=           GitHub 令牌（Token），留空表示不带身份请求
dest_root=        还原时的兜底目录，留空＝程序目录\还原
backup=yes        是否在覆盖前备份，yes / no
backup_dir=       备份放在哪，留空＝程序目录\备份

==================================================
十一、卸载
==================================================
直接删掉整个文件夹就行，程序不写注册表、不装服务、不留后台进程。
删之前记得把 备份 文件夹里的东西拷走，那里面是你之前的存档。
